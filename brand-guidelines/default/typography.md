# Typography — Default (Platzhalter)

Generische Fallback-Typografie. Ersetzen, sobald eine echte Brand vorliegt.

- **Display-Font:** Space Grotesk — https://fonts.google.com/specimen/Space+Grotesk
- **Data/Text-Font:** IBM Plex Sans — https://fonts.google.com/specimen/IBM+Plex+Sans

Keine der Banned Fonts aus `docs/motion-philosophy.md` verwenden (Inter, Roboto, Open Sans, Lato, Poppins, Outfit, Sora, Fraunces, Playfair Display, Cormorant Garamond, Syne, Cinzel, Nunito, Source Sans, PT Sans, Arimo).
